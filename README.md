# 🧮 Colorful Fraction Calculator

A vibrant, web-based interactive fraction calculator designed for high visibility and instant fraction-only calculations. Built without decimal outputs, it is optimized for educational use, circular track distance problems, and standard fractional arithmetic.

## ✨ Features

* **Zero Decimals:** All mathematical operations strictly perform exact fraction arithmetic without conversion to decimals.
* **Large, Accessible UI:** Clean layout with bold, high-contrast numbers for clear visibility.
* **Dual Calculation Modes:**
  * **Standard Mode:** Supports standard fraction arithmetic ($+$, $-$, $\times$, $\div$).
  * **Track / Distance Mode:** Specifically computes lap and track distance coverage ratios.
* **Flexible Display Options:** Dynamic toggle to view results as **Simple/Improper Fractions** or **Mixed Fractions**.
* **Step-by-Step Solutions:** Displays step details showing how fraction ratios reduce using the Greatest Common Divisor ($\text{GCD}$).
